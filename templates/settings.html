О приложении

Локальный учебный калькулятор стоимости строительных конструкций. Все данные хранятся на вашем компьютере.

Папка данных: {{ data_dir }}

  • Денежные расчёты выполняются через Decimal — без ошибок округления двоичной арифметики.
  • Каждый сохранённый расчёт хранит снимок цен и правил своей версии прайса.
  • Пароли хранятся только в виде необратимых хешей (Werkzeug).

Приложение не предназначено для размещения в открытом интернете без дополнительного усиления безопасности (HTTPS, ограничение доступа, резервное копирование).
