# Сборка портативного приложения «Калькулятор ЛидерПро» (Windows)

Инструкция по сборке **портативной версии** приложения (Python + Flask) в папку,
которую можно передать на другой компьютер и запускать двойным щелчком по EXE —
**без установки Python и без командной строки**.

Используется **PyInstaller в режиме `--onedir`** (папка с EXE и библиотеками).
Это самый простой и надёжный способ упаковать существующее Flask-приложение:
шаблоны, статика и библиотеки лежат рядом с EXE, а не распаковываются каждый раз.

---

## 1. Что требуется для сборки

* Windows 10/11 (64-бит).
* Python 3.11+ (при сборке — один раз; на машине пользователя Python не нужен).
* Интернет — чтобы установить зависимости сборки (PyInstaller).
* Исходники проекта (эта папка).

Сборка выполняется **на Windows**. Собрать Windows-EXE на другой ОС нельзя.

---

## 2. Быстрая сборка

Дважды щёлкните **`build.bat`** (или запустите его из командной строки).
Скрипт автоматически:

1. создаст виртуальное окружение `.venv` (если его нет);
2. установит зависимости приложения из `requirements.txt`;
3. установит PyInstaller из `requirements-build.txt`;
4. сгенерирует заготовку иконки `assets/app.ico` (если её нет);
5. очистит старые `build/` и `dist/`;
6. соберёт приложение по `Calculator.spec`;
7. упакует результат в `dist/Calculator-portable.zip`.

### Результат сборки

```
dist/
├── Calculator/                     <- готовая портативная папка
│   ├── Calculator.exe              <- запускной файл
│   ├── ПРОЧТИ_МЕНЯ.txt             <- краткая инструкция для пользователя
│   └── _internal/                  <- библиотеки и ресурсы (templates, static, assets)
└── Calculator-portable.zip         <- архив всей папки для передачи
```

---

## 3. Ручная сборка (если нужно по шагам)

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install -r requirements-build.txt
.venv\Scripts\python tools\make_icon.py
.venv\Scripts\python -m PyInstaller --noconfirm --clean Calculator.spec
.venv\Scripts\python tools\package_zip.py dist\Calculator dist\Calculator-portable.zip
```

## 4. Где хранятся пользовательские данные (важно)

В собранном приложении **изменяемые данные НЕ хранятся внутри папки сборки**
(она может заменяться при обновлении, а `_internal` — вообще временная папка
распаковки). Данные лежат в постоянной папке пользователя:

```
%LOCALAPPDATA%\PartitionCalculator\
├── calculator.db            <- база SQLite (расчёты, пользователи, версии прайса)
├── данные_калькулятора.xlsx  <- рабочий прайс (копия исходного шаблона; правки — здесь)
├── exports\                 <- выгруженные PDF/XLSX
├── yandex_imports\          <- временные файлы импорта прайса с Яндекс Диска
├── logs\app.log             <- журнал приложения
├── logs\console.log         <- вывод сервера (в собранном виде нет консоли)
├── secret.key               <- ключ сессий (чтобы не выходить после перезапуска)
└── app.port                 <- порт работающего экземпляра
```

* Исходный шаблон прайса (`данные_калькулятора.xlsx`) поставляется вместе с
  приложением и при первом запуске копируется в папку данных. **Исходный шаблон
  при обычной работе не изменяется** — все обновления идут в рабочую копию.
* Существующая база **никогда не перезаписывается пустой** при первом запуске.

### Переопределение папки данных

Продвинутый способ — переменная окружения `CALCULATOR_DATA_DIR`:

```bat
set CALCULATOR_DATA_DIR=D:\Kalkulyator\data
dist\Calculator\Calculator.exe
```

## 5. Перенос уже существующих данных (миграция)

Есть три безопасных способа. Ни один не удаляет и не изменяет исходные файлы.

### Способ 1. Автоматически при первом запуске (рядом с EXE)

Если положить старую папку `instance` (с `calculator.db`) или файл
`calculator.db` **рядом с `Calculator.exe`** ДО первого запуска, приложение
перенесёт базу в папку данных. Текущая рабочая папка (`cwd`) для поиска
намеренно НЕ используется.

### Способ 2. Явный перенос встроенным инструментом (рекомендуется)

```bat
:: посмотреть, что будет сделано (ничего не меняет)
.venv\Scripts\python tools\migrate_data.py --from "E:\vibecoding\calculator" --dry-run

:: перенести базу и прайс в %LOCALAPPDATA%\PartitionCalculator
.venv\Scripts\python tools\migrate_data.py --from "E:\vibecoding\calculator"
```

Поведение:

* по умолчанию существующая база **не перезаписывается** (скрипт вернёт код 2);
* с флагом `--force` перед перезаписью создаётся резервная копия
  `calculator.db.backup-ГГГГММДД-ЧЧММСС`;
* источник проверяется на признаки SQLite;
* исходные файлы не изменяются.

Ключи: `--from` (папка проекта или путь к `.db`), `--data-dir`, `--force`,
`--no-excel`, `--dry-run`.

### Способ 3. Переменная окружения

Укажите `CALCULATOR_DATA_DIR` на существующую папку данных (см. выше) — тогда
перенос не нужен вовсе.

> Встроенный инструмент никогда не запускается автоматически — только вручную.

## 6. Запуск приложения у пользователя

При двойном щелчке по `Calculator.exe` приложение:

1. запускает Flask **только** на `127.0.0.1` (без доступа из сети);
2. выбирает свободный порт (по умолчанию 5000, при занятости — следующий);
3. открывает системный браузер на странице калькулятора;
4. **не запускает вторую копию** — повторный щелчок открывает уже работающее окно;
5. при ошибке показывает понятное сообщение (подробности — в `logs\app.log`),
   без трассировки;
6. даёт **понятный способ завершения**:
   * значок приложения в системном трее → **«Завершить»**;
   * либо страница **«Настройки» → «Завершить приложение»** (для администратора);
   * при закрытии приложение корректно останавливает сервер.

Служебные переменные окружения (для диагностики/автотестов):
`CALCULATOR_PORT`, `CALCULATOR_NO_BROWSER=1`, `CALCULATOR_NO_TRAY=1`,
`CALCULATOR_EXIT_AFTER=<секунды>`.

## 7. Иконка приложения

* Поставляется заготовка `assets/app.ico` (простой значок «калькулятор» в
  фирменном зелёном цвете). Это **осознанная заготовка**, а не случайная картинка.
* Чтобы поставить свою иконку — замените `assets/app.ico` (формат ICO,
  желательно размеры 16/32/48/256) и пересоберите приложение.
* Иконка используется и для EXE, и для значка в трее.
* Скрипт `tools/make_icon.py` умеет заново сгенерировать заготовку.

---

## 8. SmartScreen и безопасность

* Приложение **не отключает** SmartScreen/антивирус и не обходит проверки.
* Неподписанный EXE может вызвать предупреждение Windows SmartScreen
  («Windows защитила ваш компьютер»). Это нормально для самосборки:
  нажмите «Подробнее» → «Выполнить в любом случае».
* Чтобы убрать предупреждение у других пользователей, нужна **цифровая подпись
  кода** (сертификат). Для портативной сборки это не обязательно.
* Приложение слушает только `127.0.0.1` и не предназначено для открытия в
  интернете.

---

## 9. Как передать на другой компьютер

1. Передайте архив `dist/Calculator-portable.zip`.
2. На другом компьютере распакуйте его в удобное место (кириллица и пробелы в
   пути поддерживаются).
3. Запустите `Calculator.exe` двойным щелчком.
4. Данные создадутся в `%LOCALAPPDATA%\PartitionCalculator` при первом запуске.

Python на принимающей машине **не нужен**.

## 10. Тестирование и статус

Автоматические тесты проекта (в т.ч. миграции и путей):

```bat
.venv\Scripts\python -m pytest tests -q
```

Что проверено фактически на этой машине:

* запуск `Calculator.exe` двойным щелчком (через отдельный процесс) и авто-
  открытие страницы (через HTTP-обращения: `/login`, `/static/...`);
* запись данных в постоянную папку пользователя, а не в `_internal`;
* полный сценарий: создание администратора → вход → загрузка прайса →
  расчёт → сохранение → просмотр → экспорт PDF/XLSX;
* сохранение расчёта между перезапусками;
* неизменность сохранённого расчёта после обновления прайса;
* миграция базы: dry-run, обычный перенос, отказ без `--force`, `--force` с
  резервной копией, неизменность исходной базы;
* отсутствие ошибочного импорта «посторонней» базы из текущей рабочей папки.

Что стоит перепроверить вручную (не покрыто автотестом в этой среде):

* визуальный вид значка в трее и открытие браузера при **реальном** двойном
  щелчке (в автотесте браузер и трей отключались переменными окружения);
* предупреждение SmartScreen на «чистой» машине;
* работа на компьютере без установленного Python (гарантируется PyInstaller,
  но проверяется на отдельной машине).

---

## 11. Пересборка после изменений

После правок в коде/шаблонах/статике просто снова запустите `build.bat`.
Папка данных пользователя при этом не затрагивается — обновляется только
`dist/Calculator`.

| Файл | Назначение |
