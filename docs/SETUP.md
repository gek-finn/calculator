# Калькулятор «ЛидерПро» (учебная версия)

Локальное веб-приложение для расчёта стоимости строительных конструкций по прайсу.
Создано как **учебный проект**: интерфейс вдохновлён скриншотом калькулятора компании
«ЛидерПро», но цены и правила честно разделены на подтверждённые и учебные допущения.

## Запуск на Windows

1. Установите Python 3.11+ с сайта python.org (отметьте «Add python.exe to PATH»).
2. Дважды щёлкните по файлу **`запуск.bat`**.
3. При первом запуске скрипт:
   - создаст виртуальное окружение `.venv`;
   - установит зависимости из `requirements.txt`;
   - создаст базу `instance/calculator.db` (если нет);
   - создаст учебный прайс `данные_калькулятора.xlsx` (если нет).
4. Браузер откроется на `http://127.0.0.1:5000/` автоматически.

Приложение слушает **только** `127.0.0.1` — в интернете оно без дополнительной
защиты работать не должно.

## Первый вход

Встроенного скрытого пароля нет. На первом запуске откройте страницу **`/setup`**
(она откроется сама при отсутствии пользователей) и создайте учётную запись
администратора: логин и пароль задаёте вы. Пароль хранится только в виде
необратимого хеша (Werkzeug).

### Как создать сотрудников и сменить пароль

1. Войдите администратором.
2. Раздел **«Пользователи»** (боковое меню):
   - «Новый сотрудник» — логин, ФИО, пароль, роль (`Менеджер` / `Администратор`);
   - возле любого сотрудника: смена пароля, роли, включение/отключение.

## Работа с расчётом (обязательная последовательность)

1. **«Загрузить данные»** — читает `данные_калькулятора.xlsx`, проверяет листы,
   колонки, типы, дубликаты ID, проценты и активность. При ошибках прайс
   **не загружается**, выводится список ошибок с листом и строкой. При успехе
   показываются версия, дата и количество позиций; версия сохраняется в SQLite.
2. **«Начать расчёт»** — карточка клиента + одна или несколько конструкций
   (тип, профиль, размеры в мм, количество, стекло, фурнитура), услуги,
   скидка. Площадь и промежуточная стоимость пересчитываются автоматически.
3. **«Показать итог»** — серверный расчёт с расшифровкой каждой суммы,
   скидкой и итогом. Сохранение в историю фиксирует версию прайса и снимок цен.

## Важно о ценах (честность данных)

- **Подтверждено скриншотом**: минимальная стоимость межкомнатной перегородки
  120 000 ₽; надбавки за стекло (0/10/22/35/35/40/40 %); фурнитура
  (доводчик 8000, замок 3500, ручка 2000, закладная 2500 ₽); услуги
  (доп. материалы 8500, замер 2500, доставка по Уфе 6000, монтаж 35000,
  проживание 0 ₽).
- **Противоречие исходного скриншота сохранено**: итог по фурнитуре там
  равен 12 000 ₽, хотя сумма отмеченных позиций — 16 000 ₽. Приложение всегда
  считает фурнитуру из фактически выбранных позиций.
- **Неизвестно и требует заполнения**: базовая цена стекла за м² (до заполнения
  расчёт стекла блокируется — цена никогда молча не становится нулём), цена
  погонного метра профиля 38×38 (правило расчёта погонных метров отключено,
  пока не задано явно), базовые цены и правила большинства конструкций.

Заполнить неизвестные цены: **Прайс → (админ) изменить значение → Сохранить**.
При этом создаётся новая версия прайса, пишется история изменений, а Excel
перезаписывается с резервной копией.

## Обновление прайса с Яндекс Диска

Кнопка **«Получить актуальный прайс с Яндекс Диска»** (на главной странице и на
странице «Прайс») скачивает Excel-прайс по публичной ссылке
`https://disk.yandex.ru/d/YOUR_PUBLIC_PRICE_LINK`.

Источник задан в коде приложения (`YANDEX_PRICE_PUBLIC_URL` в `app.py`) и
**не принимается от пользователя**. Обновление выполняется **только по кнопке** —
автоматических загрузок при запуске нет.

Порядок работы:

1. Нажатие кнопки. Приложение получает ссылку на скачивание через официальный
   API публичных ресурсов Яндекс Диска и скачивает файл во временную папку.
   Логин, пароль и токены не используются.
2. Страница предварительного просмотра: дата и время получения, имя/формат/размер
   файла, число прочитанных позиций, изменения цен (сумма и процент), новые
   позиции, отсутствующие позиции, позиции, требующие ручного сопоставления, и
   ошибки проверки.
3. **«Подтвердить и применить прайс»** — создаётся новая версия прайса,
   рабочий Excel-файл заменяется (с резервной копией), пишется история изменений.
   **«Отменить обновление»** — временный файл удаляется, прайс не меняется.

Правила безопасности:

- до подтверждения рабочие цены не меняются;
- при блокирующих ошибках структуры или данных применение запрещено;
- отсутствующие в источнике позиции **не обнуляются** и не удаляются молча —
  требуется явное подтверждение; они просто исчезают из новой версии прайса;
- ранее сохранённые расчёты не меняются: каждый хранит свой снимок цен, а
  пересчёт по актуальному прайсу остаётся отдельной явной операцией;
- есть тайм-ауты запросов и ограничение размера файла (20 МБ);
- временная ссылка на скачивание не сохраняется как постоянный адрес источника;
- поддерживаются форматы `.xlsx` (openpyxl) и `.xls` (xlrd);
- позиции сопоставляются по устойчивому `id`; если `id` пуст или повторяется,
  строка помечается «требует ручного сопоставления» и обновление блокируется.

## Тесты

```bat
.venv\Scripts\python.exe -m pytest tests -q
```

Покрытие: площадь 4000×2500 = 10 м²; референсная сумма 184 000 ₽
(120 000 + 12 000 + 8500 + 2500 + 6000 + 35 000); скидка 5 % = 9200 ₽;
итог 174 800 ₽; пересчёт при изменении размеров, количества, стекла;
отключение услуги; отклонение некорректного прайса; сохранение итога старого
расчёта после обновления прайса; недоступность админ-панели менеджеру;
сохранение истории между перезапусками.

Отдельный набор тестов (`tests/test_yandex_price.py`) проверяет обновление прайса
с Яндекс Диска **без обращения к реальному источнику** (HTTP-запросы
подменяются): успешный импорт `.xlsx` и `.xls`; недоступность Диска; ошибка API и
отсутствие ссылки на скачивание; тайм-аут и обрыв загрузки; HTML вместо Excel;
слишком большой и повреждённый файл; отсутствие обязательных столбцов;
некорректные цены и дубликаты id; новые и отсутствующие позиции; отмена
обновления; ошибка сохранения не портит прежний прайс; старый расчёт сохраняет
первоначальную сумму; новый расчёт использует обновлённые цены; повторный импорт
не создаёт дубликатов.

Проверка **реального** источника (включается вручную):

```bat
set YANDEX_LIVE_TEST=1
.venv\Scripts\python.exe -m pytest tests/test_yandex_price.py::test_live_yandex_disk -q
```

Отдельные тесты (`tests/test_app_paths.py`, `tests/test_launcher.py`,
`tests/test_migrate_data.py`) проверяют раскладку путей и постоянную папку данных,
миграцию (в том числе отсутствие ошибочного импорта базы из текущей рабочей
папки), выбор свободного порта и перенос данных с резервным копированием.

## Портативная сборка для Windows (запуск без Python)

Приложение можно собрать в папку, которую передают на другой компьютер и
запускают **двойным щелчком по EXE** — без установки Python и командной строки.

```bat
build.bat
```

Результат: `dist\Calculator\Calculator.exe` и архив `dist\Calculator-portable.zip`.

* Данные (база, прайс, экспорт, журналы) в собранном виде хранятся в постоянной
  папке `%LOCALAPPDATA%\PartitionCalculator` и НЕ теряются при обновлении
  программы. Исходный Excel-шаблон копируется в папку данных при первом запуске
  и при обычной работе не изменяется.
* Перенос старых данных: положите папку `instance` рядом с EXE до первого
  запуска, либо выполните `python tools\migrate_data.py --from "старая папка"`
  (по умолчанию существующая база не перезаписывается; при `--force` создаётся
  резервная копия). Можно также задать `CALCULATOR_DATA_DIR`.
* Подробная инструкция по сборке, иконке, SmartScreen и тестированию —
  в **`README_BUILD.md`**.

## Структура

| Файл | Назначение |
|---|---|
| `запуск.bat` | установка и запуск на Windows |
| `build.bat` | сборка портативного приложения (PyInstaller) |
| `Calculator.spec` | конфигурация сборки PyInstaller |
| `run_app.py` | точка входа собранного приложения (порт, браузер, трей, логи) |
| `app_paths.py` | пути к ресурсам и постоянной папке данных, миграция |
| `app.py` | Flask-приложение, маршруты, авторизация |
| `database.py` | SQLite: пользователи, версии прайса, расчёты, история цен |
| `calculator.py` | расчёт стоимости (Decimal, явные типы начислений) |
| `price_service.py` | чтение/проверка/создание/экспорт Excel-прайса (.xlsx и .xls) |
| `yandex_disk.py` | скачивание прайса с Яндекс Диска по публичной ссылке |
| `price_diff.py` | сравнение действующего прайса и файла с Яндекс Диска |
| `данные_калькулятора.xlsx` | прайс (создаётся автоматически, при вас не перезаписывается) |
| `tools/migrate_data.py` | явный перенос существующей базы и прайса (с бэкапом) |
| `tools/make_icon.py` | заготовка иконки приложения |
| `tools/package_zip.py` | упаковка сборки в ZIP |
| `templates/`, `static/` | интерфейс |
| `tests/` | pytest-тесты |

Для знакомства с расчётом заполните учебные тарифы в созданном Excel-прайсе. Пустая базовая цена стекла блокирует расчёт намеренно. Публичная ссылка на прайс в app.py заменена шаблоном; укажите собственную, чтобы использовать обновление с Яндекс Диска.
